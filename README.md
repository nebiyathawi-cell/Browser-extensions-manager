# Frontend Mentor - Browser extensions manager UI

![Browser extensions manager screenshoot ](./Screenshot%20(73).png)

## Welcome! 👋



A responsive browser extensions manager built with HTML, Tailwind CSS, and JavaScript.

## Features

- Display browser extensions.
- Filter extensions by All, Active, and Inactive.
- Toggle extension status.
- Remove extensions.
- Dark and light theme.
- Persist extension changes and theme preferences using localStorage.

## Technologies

- HTML5
- Tailwind CSS
- JavaScript
- Fetch API
- LocalStorage

## Getting Started

1. Clone this repository.
2. Open the project using VS Code.
3. Run it with Live Server.

## What I Learned

- Array methods (`map`, `filter`, `splice`).
- Fetch API and asynchronous JavaScript.
- JSON parsing and stringification.
